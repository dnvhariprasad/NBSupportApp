The DQL console

POST /api/query/execute
Content-Type: application/json

{ "dql": "select r_object_id, object_name from cms_user_profile where user_login_name = 'cto.dit'" }

Response: {"columns":[…],"rows":[{…}],"totalCount":n,"limit":10000}. The fastest way to verify repository state when diagnosing. r_object_id is always included.
