What this application is

NBAdminApp — deployed as neoadmin — is the administration portal for the NABARD case-management platform. It is a separate application from the CMS three-tier stack (frontend/, backend/, Middleware/), and it does not share code with it. Users, groups, verticals, departments, grades, delegation and reporting are administered here.

Because administration lives here rather than in the CMS, support tickets that look like CMS work often land in this repository. A reported problem with "verticals" or "user grades" is far more likely to be a NBAdminApp change than a CMS one.

There is no database and no JPA layer. Every read and write is a DQL query or an object manipulation against the Documentum repository, issued over HTTP. This is the single most important fact about the codebase: what looks like a data-access layer in a conventional Spring application is, here, a REST client that speaks DQL.

There is no test infrastructure. No test runner, no test dependencies, no test files — in either tier. spring-boot-starter-test is declared in pom.xml but no tests exist, and the frontend package.json has no test script at all. Verification in this codebase means running the application and querying the repository directly.
